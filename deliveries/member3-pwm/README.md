### 环境和配置
*   **开发板和 MCU 完整型号**：NUCLEO-F446RE / STM32F446RETx
*   **STM32CubeIDE 版本 / HAL 软件包版本**：STM32CubeIDE 1.17.0 / 系统默认自带版本
*   **系统时钟、外设时钟、定时器实际时钟**：系统时钟 (HCLK) 84MHz，APB1 定时器时钟 84MHz
*   **引脚、接线、电平、外设实例和通道**：引脚 PB6 (对应板子外侧 `PWM/CS/D10` 针脚)，外设 TIM4，通道 Channel 1。高电平有效。
*   **中断、优先级、触发方式**：无。纯硬件 PWM 输出，不占用任何 CPU 中断。
*   **如涉及定时器，PSC / ARR / 捕获极性 / 溢出策略**：Prescaler = 0，Counter Period (ARR) = 4199，无输入捕获，自动重装载计数溢出。

### 集成方法
*   **需复制的文件、依赖和需修改的工程设置**：需复制 `motor_pwm.c` (放入 `Core/Src`) 和 `motor_pwm.h` (放入 `Core/Inc`)。无特殊依赖，只需工程包含标准 HAL 库。
*   **初始化及启动函数、调用顺序**：
    1. 在 `main.c` 的 `/* USER CODE BEGIN Includes */` 中包含 `#include "motor_pwm.h"`。
    2. 在 `/* USER CODE BEGIN 2 */` 中调用 `Motor_PWM_Init();` 初始化并启动 PWM。
*   **对外函数和共享变量（名称、类型、单位、有效范围）**：
    *   `void Motor_SetSpeed(uint8_t speed);`
    *   参数 `speed` 为 0 - 100 的整数（代表 0% - 100% 占空比），超出 100 会被自动限制为 100。
*   **HAL 回调及其所属文件**：本模块无中断回调。
*   **数据何时有效、多久更新、失效或超时如何表示**：调用 `Motor_SetSpeed` 后立即生效。
*   **与其他模块的依赖及可能冲突**：
    *   本模块独占了 **PB6** 引脚，其他模块禁止占用。
    *   未占用 PA0 (ADC) 和 PA7 (编码器)。
    *   本模块未配置方向控制引脚 (AIN1/AIN2)，需由系统集成时分配其他空闲 GPIO 进行控制。
