## 模块边界

| 模块 | 需要约定的数据和接口 |
| --- | --- |
| 按键 | 正转/反转请求、消抖、同时按下时的规则 |
| PWM | 初始化、启动、设置占空比、方向、停机及换向流程 |
| 输入捕获 | 周期与高电平计数，或能计算两者的边沿时间戳；计数单位、溢出处理、数据有效标志 |
| ADC | 原始值、分辨率、更新时间与有效标志 |
| 计算 | 周期、频率、编码器占空比、输出轴 RPM、最低可测 RPM、有效状态 |
| 应用与展示 | ADC 到占空比的映射由谁负责；刷新频率、快照一致性、测量超时策略 |

避免多个模块同时设置同一个控制量。HAL 回调需统一分派，避免重复定义。中断中尽量只记录数据或置标志，避免长延时和高频 printf。多个共享字段须作为一致快照读取，单独加 volatile 不保证整组数据一致。

## 测量约定

- PWM 固定为 TIM4_CH1 / PB6 的 20 kHz 信号；捕获输入为 TIM3_CH2 / PA7；电位器输入为 ADC1_IN0 / PA0。
- 编码器 A 通道每个电机轴转动一圈产生 11 个脉冲。减速比为 30:1，因此每个输出轴转动一圈对应 330 个上升沿。
- 若 f 表示 A 通道完整脉冲频率，输出轴 RPM = 60 × f / 330。不能把双边沿计数率直接当作该脉冲频率。
- 编码器占空比需要高电平持续时间和完整周期；仅有相邻上升沿不足以得到占空比。
- PWM 占空比与编码器信号占空比分开标注。
- 单独测量 A 通道不能独立判断实际旋转方向；若展示命令方向，应明确标签。
- 最低可测 RPM = 60 / (330 × 最大可靠可测脉冲周期)。最大可靠周期需要结合实际计数频率、ARR、溢出处理和超时限制确定。
- 无新脉冲时不能立即判断为停止，低速、超时及数据失效的显示规则需与 Member 6 一致。

## 集成顺序

1. 统一初始化、引脚、时钟、中断与 HAL 回调，确认能够编译和下载。
2. 验证 ADC 与 PWM，再验证驱动和正反转。
3. 接入编码器捕获，检查原始计数和溢出处理。
4. 接入计算与展示，检查单位、有效状态和数据更新。
5. 完成验收清单，演示前固定版本。
