# 集成验收清单

以下项目尚未验证。完成实际测试后再勾选，并记录证据。

## 课程要求

- [ ] 两个按钮分别以中断方式控制正转和反转。
- [ ] 电位器由 ADC1_IN0 / PA0 以中断方式采集，并用于调节 PWM 占空比。
- [ ] TIM4_CH1 / PB6 输出硬件 PWM，经 AT8236 驱动 MC520。
- [ ] 逻辑分析仪验证 PWM 频率 20 kHz、周期 50 μs，并验证不同占空比。
- [ ] TIM3_CH2 / PA7 使用输入捕获中断，记录编码器边沿对应的计数。
- [ ] 展示编码器周期（s）、频率（Hz）、信号占空比（%）。
- [ ] 展示减速后输出轴 RPM，并核对 330 脉冲/输出轴圈的换算。
- [ ] 确定最低可测输出轴 RPM，说明计数配置、编码器分辨率及溢出处理的依据。
- [ ] 使用 SWV printf 或 STM32CubeMonitor 展示数据。
- [ ] 使用断点、单步和变量检查验证配置、中断、捕获值和计算结果。
- [ ] 全部成员完成自己负责部分的演示彩排，正式考核版本无需现场改代码或调参。

## 建议增加的稳定性检查

- [ ] 低速和无新脉冲时显示有效状态，不持续把旧值当作新测量。
- [ ] 零周期、无效计数不会导致除零。
- [ ] 按键消抖和换向规则符合已确认的设计。
- [ ] 不同方向下，电位器与有效驱动比例的关系正确。
- [ ] 数据显示不会明显干扰输入捕获中断。
- [ ] 复位后可重复运行，完整源码可以重新编译。
